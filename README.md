# Expense Tracker MCP Server

A Python-based MCP server built with FastMCP that enables AI assistants to interact with an expense-tracking system through structured tools. The project demonstrates how to connect AI applications with external functionality using the Model Context Protocol (MCP).

## Project Overview

This project explores MCP fundamentals by implementing tools to add expenses, retrieve expense records, and calculate spending totals. It uses SQLite for persistent storage and FastMCP to expose Python functions as MCP tools.

## Key Features

- Add and record expenses.
- List expenses by category.
- Calculate spending totals over a date range.
- Persist expense records using SQLite.
- Test and inspect MCP tools using MCP Inspector.
- Integrate with compatible AI clients.

## Tech Stack

Python · FastMCP · SQLite · uv · Model Context Protocol (MCP)

## Learning Objectives

Understand MCP server initialization, tool registration, client-server communication, tool execution, and integration with AI assistants.
